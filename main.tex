\begin{abstract}
Interactive applications demand photorealistic, real-time rendering, but traditional baking pipelines struggle to capture highly reflective, view-dependent materials. Simultaneously, modern neural and splat representations achieve exceptional novel-view synthesis but rely on ambient 3D space distributions that do not cleanly integrate with standard mesh-based rasterization pipelines. To bridge this gap, we introduce Automatic Neural Baking, a novel, differentiable pipeline that bakes view-dependent appearance directly onto an explicit 3D mesh as a strictly 2D manifold representation. Our method models appearance using three rasterizer-native modules: a 2D Gaussian Mixture Model anchored to the mesh via barycentric coordinates for diffuse color and reflectivity; an adaptive, hierarchical environment map that decomposes the object into near-convex parts to capture self-reflection; and a lightweight Kolmogorov-Arnold Network (FastKAN) that evaluates the reflection equation for high-frequency specularities. By restricting primitives to the 2D surface, our representation avoids depth-sorting and co-planar degeneracies entirely. The resulting assets can be evaluated locally within a standard fragment shader, achieving real-time rendering speeds (over 60 FPS) while surpassing current state-of-the-art methods on standard novel view synthesis benchmarks.
\end{abstract}
